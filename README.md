# 儿童任务积分系统

家庭任务管理与积分奖励，让孩子通过完成任务赚积分、兑换奖励，培养责任感和成就感。

## 功能特色

- **零登录** — 群组链接即访问凭据，收藏即用、分享即协作
- **多孩子支持** — 一个家庭群组可添加多个孩子，各自独立积分
- **星级评价** — 完成任务 1-5 星评价，鼓励认真对待每一项任务
- **限时翻倍** — 每日随机 3 个任务获得 1.5x-2.0x 倍率加成
- **悬赏挑战** — 接受额外条件赚更多积分，完成翻倍、失败扣减
- **任务上锁** — 奖励可绑定钥匙任务，支持灵活分组：同一 lock_group 内钥匙任选其一完成即可（或关系），不同 lock_group 之间每组各需完成一个（与关系），未分组的钥匙不参与锁判定。教孩子先尽责后享受。也可用解锁券绕过，但需额外付费，明白走捷径有代价
- **时段定价** — 奖励按时段自动涨降价，旁敲侧击引导孩子认识什么时候该玩、什么时候该学习
- **奖章优惠券** — 完成任务得奖章，积累兑换优惠券降低奖励花费，鼓励多完成任务多学习
- **贷款应急** — 积分不够可借款，按时还款积累信用提升额度
- **惩罚节制** — 扣分有多档上限，避免情绪化操作
- **撤回支持** — 所有操作可撤销，不怕误操作

## 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env   # 编辑填入数据库连接
bash run.sh            # 访问 http://localhost:8001
```

首次启动自动建表。本地开发默认连接本地 PostgreSQL `kids_rewards` 库。

部署方案有多种选择：

- **Vercel + Supabase** — 零成本，无需管服务器
- **自建 VPS** — 国内访问快，完全掌控
- **Cloudflare Tunnel** — 用家里电脑/NAS 搭建
- **其他** — GitHub Pages、Cloudflare Pages 等静态托管 + 后端分离

## 积分规则

### 星级折算

任务基础分按完成质量折算：

| 星级 | 折算 | 说明 |
|------|------|------|
| 1 星 | 50% | 敷衍了事 |
| 2 星 | 60% | 还需努力 |
| 3 星 | 80% | 基本完成 |
| 4 星 | 100% | 完成得很好 |
| 5 星 | 120% | 超额完成 |

最终积分 = 基础分 × 星级倍率 × 翻倍倍率 × 条件倍率

### 惩罚冷静期

扣分有限制，防止一时生气扣太多：

| 窗口 | 上限 |
|------|------|
| 10 分钟 | 10 分 |
| 1 小时 | 25 分 |
| 24 小时 | 100 分 |

## 贷款

积分不够时可以借款，按时还清积累信用。

| 信用分 | 冷却期 | 额度 |
|--------|--------|------|
| 0-49 | 28 天 | 50 |
| 50-99 | 14 天 | 100 |
| 100-149 | 7 天 | 200 |
| 150-199 | 7 天 | 400 |
| 200+ | 7 天 | 800 |

- 日利率默认 5%，单利不计复利
- 支持部分还款，还多少减多少本金
- 1 天内还清信用 +5，拖越久加越少甚至扣信用
